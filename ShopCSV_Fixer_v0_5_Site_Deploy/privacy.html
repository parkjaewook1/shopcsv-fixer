TRANSPARENT SECURITY

Privacy and safety limits

Current version: 0.5.1 public beta candidate. ShopCSV Fixer is an independent project and is not endorsed by Shopify.

Your files

Supplier CSV files are processed in your browser, not uploaded to a ShopCSV Fixer server. The tool does not connect to your Shopify account. In its current build, it makes no application fetch requests or sends any file content over the network.

Local saved profiles

Saved mapping profiles contain their label and source CSV column names, not product rows. Profiles are stored using browser localStorage on your device. Column names might themselves be sensitive; use generic names where appropriate. You can delete saved profiles from the tool or clear site storage in your browser.

Feedback

The optional feedback survey is hosted by Tally. Opening our feedback page does not upload CSV files or send saved column mappings to Tally. If you choose to open and submit the survey, the answers you enter are collected by Tally and become visible to the ShopCSV Fixer project owner. Tally also processes ordinary request metadata according to its privacy information. Do not include customer data, private supplier files, passwords or API keys.

Analytics and hosting

This site has no advertising pixels and does not track CSV values, product rows, profile names, or files. The operator may enable Cloudflare Web Analytics for aggregated page-visit and performance statistics. When enabled, Cloudflare inserts a browser beacon; it does not measure CSV validation or download button clicks. The beacon and hosting provider receive ordinary network request and page-performance metadata. The policy allows only the Cloudflare Analytics script and metric endpoint, not unrestricted remote requests. If Web Analytics has not been enabled by the owner, no analytics beacon is added by this project.

Security and import limitations

We block suspected spreadsheet formulas and HTML markup in mapped text fields, limit file sizes and row counts, and escape displayed CSV content. Nevertheless, browser parsing and spreadsheet behavior vary. Do not treat the output as a guarantee that every Shopify CSV import will succeed. This tool does not check whether remote image URLs really exist, and it does not verify actual inventory or existing products in your Shopify store.

Use test imports first. Exports are draft and unpublished; turn off overwrite when importing. Back up your store data before any large bulk operation. Never import a CSV that you haven't reviewed.

Third-party links

External Shopify help links are optional and open in a new browser tab. The tool does not load their content inside its own pages.
